Simulasi Risiko Kredit

Model LightGBM pada data Home Credit Default Risk. Isi data pemohon, lihat probabilitas gagal bayar, kelompok risiko, dan faktor pendorongnya.

Pinjaman
Pemohon
Skor kredit eksternal (0 sampai 1)
Riwayat kredit (opsional)

Kolom yang dikosongkan dianggap "tidak ada data", dan model memperlakukannya sebagai nasabah tanpa riwayat tersebut.

Hasil akan tampil di sini. Coba tombol contoh di kiri atas.

Ini demo portofolio, bukan alat keputusan kredit. Keputusan memakai asumsi finansial ilustrasi (untung 10%, rugi 60%), dan faktor risiko menjelaskan perilaku model, bukan sebab-akibat. Form ini hanya mengisi sebagian dari 164 fitur model. Dokumentasi API: /docs.
